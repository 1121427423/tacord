# 00 · 设计总纲

## 0.1 一句话定义

一款 **3D 斜俯视战术指挥游戏**：玩家扮演指挥官，只下达"意图级"命令；麾下每一个士兵都是独立求生的个体，他们根据**周围物体的真实形状**寻找掩体、判断火力、记住子弹从哪来、救助倒下的战友、押送俘虏、修筑工事——没有任何预设的掩体标记，也没有脚本化的行为。

## 0.2 六条设计支柱（Pillars）

这六条是不可妥协的约束。任何功能如果不能推进其中至少一条，就不该在这个版本里。

| # | 支柱 | 含义 | 反例（我们绝不做） |
| --- | --- | --- | --- |
| P1 | **真实的墙，真实的掩体** | 掩体由场景几何实时派生：墙、木箱、汽车、残骸、战壕、窗沿、弹坑都可以当掩体。侧翼一旦被包抄，这处掩体立即失效。 | 关卡里手工摆放 cover point / 导航标记；"躲进掩体"= 站到某个点上播放动画 |
| P2 | **他们像真正的士兵一样作战** | 矮墙后蹲下→起身开火→伏低；高墙角探身→侧射→缩回。蹲下就真的看不见，站起来就真的会暴露。看见与命中用同一套函数。 | 无敌帧、伪装的射击动画、"掩体里减伤 50%"这种抽象数值 |
| P3 | **他们会听、会记、也想活下去** | 转向看不见的枪声、用无线电共享敌情、记住弹道来向；除非你下令，否则不会大摇大摆穿过火力杀伤区。 | 全知 AI、背后被摸不掉血、永远直冲目标 |
| P4 | **每一发子弹都算数** | 子弹是实体；近失弹会压制、会钉住人；弹药真的会打光，阵地会沉寂，长点射退化为单发，士兵会从尸体上摸走弹匣。 | 无限弹药、命中率靠随机数表、"弹药"只是一个冷却条 |
| P5 | **绝不丢下任何人** | 倒下 ≠ 阵亡。爬行、呼救、被拖回、就地救治、担架后送；每次倒下都更虚弱，运气终会用完。 | 血条归零即消失 |
| P6 | **没有什么是凭空建成的** | 放下蓝图，士兵走过去亲手建造，战斗仍在继续。补给靠卡车沿路运输，链路被切断，断点之后全线瘫痪。 | 点击建筑 → 进度条 → 建筑凭空出现 |

### 支撑 P1–P6 的"细节层"（Juice that is actually mechanics）

- 手榴弹会被胆子大的家伙捡起来扔回来；
- 爆炸把人掀飞，有些人能爬起来，头晕目眩；
- 翻越、滑铲进入掩体、扑倒躲弹、贴身肉搏；
- 机枪手倒下，有人冲上去捡起机枪接着打；
- 坦克撞穿墙、装甲跳弹、打断履带趴窝、殉爆把炮塔炸飞；RPG 射手会绕后；
- FPV 自杀无人机从头顶逼近，士兵听得到、会射击、会在最后一刻扑倒；
- 他们会说话：命令、中弹、呼叫医护兵都会冒出对话气泡（同时也是 AI 状态可读性的载体）。

## 0.3 目标平台与玩家

- **首要平台**：macOS 13+ / Apple Silicon（arm64），原生构建，不允许依赖 Rosetta 2。
- **次要平台**：Windows x86_64、Linux x86_64（用于 CI 与低成本测试）。**不承诺** Intel Mac（MoltenVK 路径保留但不作为 QA 目标）。
- **目标玩家**：喜欢《Door Kickers》《Full Spectrum Warrior》《Men of War》《Command Ops》与 RTS 战术层、但希望"命令下达后自己看戏"的玩家；单人战役 / 与朋友在线合作 / 与朋友对战。
- **单局规模**：默认 40–120 名士兵、200–400 个可交互几何体、1–2 个 FOB；压力测试目标 400 名士兵同屏（M1 1080p60）。

**证据强度分级**（R11 —— 原文档用单帧支撑整段结论，属于过度推断）：

| 结论 | 证据强度 | 能否作为设计依据 |
| --- | --- | --- |
| 主玩法画面为暖沙/土黄色调（part1 0–22s + part2 24–40s，**16 帧一致**） | **较强** | ✅ 可作为美术方向的**初始假设** |
| 存在冷灰的 UI / 说明性段落（part1 22–42s，**10 帧一致**） | **强** | ✅ |
| part2 40–84s 是"收尾/文字段落" | **弱（1 帧）** | ❌ **不作为依据**，仅登记为待验证假设 |

**由此得到的美术假设（不是定稿）**：战场主色偏暖沙/土黄（低饱和、高明度），UI/指挥层用冷灰与近白，
形成"战场暖、指挥冷"的对比，有利于俯视下单位与地形的可读分离。
**定稿条件**：人工看完整段视频并回填 `_open_visual_questions.md` 后，才能写进美术规范。

**待人工确认项**（需要在真机上人眼核对，写入 `docs/design/_open_visual_questions.md`）：
1. 相机默认俯角与可缩放范围（决定我们的相机参数初值）；
2. 单位的屏幕占比（决定角色比例与 UI 图标尺寸）；
3. HUD 布局：单位状态条、命令反馈、雷达/小地图的信息密度；
4. 交火时的镜头语言（是否切近景 / 是否有 cinematic 跟随）。

## 0.5 核心玩法循环

```
         ┌──────────────── 战略层（分钟级）────────────────┐
         │  选择 FOB 位置 → 修路 → 补给卡车往返 → 造建筑/工事 │
         │  敌方指挥官同时在做同样的事，并盯着你的 FOB      │
         └───────────────┬──────────────────────────────┘
                         │ 补给 / 兵力上限 / 情报
         ┌───────────────▼──────────────────────────────┐
         │  战术层（十秒级）：给班下达"拿下那栋楼 / 压制 / 撤退" │
         └───────────────┬──────────────────────────────┘
                         │ 命令（意图，不是输入）
         ┌───────────────▼──────────────────────────────┐
         │  班组层：交替跃进 / 火力掩护 / 担架组 / 押送组      │
         └───────────────┬──────────────────────────────┘
                         │ 角色分配
         ┌───────────────▼──────────────────────────────┐
         │  士兵层（秒级）：选掩体 → 探身开火 → 缩回 → 换弹     │
         │              受伤 → 爬行 → 被拖回 → 救治 → 归队    │
         └──────────────────────────────────────────────┘
```

**反馈回路**：交火消耗弹药与人力 → FOB 补给与医疗帐篷决定你能撑多久 → 情报（侦察/俘虏口供）决定下一次交战的信息差 → 谁先断补给链，谁的阵地就先沉默。

## 0.6 范围与非目标（Scope / Non-goals）

### EA（首发，≈20 周）—— 只做"验证核心差异"的切片

> 原计划"1–2 人 38 周交付战役 + 两张地图 + 全部 P1–P6 + 联网"不可信（R7）。EA 范围收缩如下，
> 其余按 `90-roadmap-acceptance.md` §90.1.2 的 **go/no-go 门槛**解锁，而不是默认进入首发。

- **模式**：单机遭遇战（Skirmish）vs AI；
- **地图**：1 张 1024m × 1024m 沙漠城镇（昼）+ 同一布局的夜战变体（尺寸冻结见 `05-frozen-parameters.md` §1）；
- **内容**：掩体来自真实几何、单兵/班组 AI、压制与士气、伤员链路、弹药经济、可解释性 UI —— **核心差异全在**；
- **不含**：基地建造/补给链、坦克/FPV、俘虏审讯/地道、战役、多人。

### 1.0（解锁后追加，≈18 周）
- 战役关卡序列；第 2、3 张地图；两个阵营的特色（叛军地道网络与牢房）；
- 基地建造与补给链、工事、占领与失败条件；坦克、RPG 绕后、FPV 无人机、医疗帐篷与担架队；
- 俘虏/审讯/倒戈；在线合作（2 人共同指挥）+ 在线对战（1v1）。

### 明确不做（EA 与 1.0）
- 剧情过场、角色养成、单人 FPS 直接操控（玩家永远是指挥官，跟随视角只是"只读观战"）；
- 现代政军题材之外的科幻/奇幻内容；
- 大地图战略层（世界地图、回合制战役）—— 至多做成关卡序列 + 简报；
- 主机平台、移动端、Steam Deck 之外的掌机；
- **权威服务器 + 按玩家过滤的隐藏信息**（lockstep 的必然取舍见 §10.9.1：模拟无秘密、呈现有迷雾）；
- 用户生成战役编辑器（1.0 只提供场景 JSON/ron 的手工编辑，官方地图编辑器放到 1.x）。

## 0.7 术语表

| 术语 | 定义 |
| --- | --- |
| **柱 / Column** | 世界在 XZ 平面上按 0.5m 栅格切分出的一根体素柱，记录高度、材质、实体状态。世界的最小几何单元。 |
| **Chunk** | 32×32 根柱构成的区块，是网格重建、掩体重算、流式加载的单位。 |
| **Cover Slot（掩体槽）** | 由柱的自由面派生出的可站位候选点，含法线、高度、宽度、类型、占用者。 |
| **Blocking（遮挡度）** | 从某威胁方向看，士兵身体采样点被几何遮挡的加权比例，0=全暴露，1=完全藏住。 |
| **Flanked** | 威胁方向与掩体法线夹角超过该掩体的有效遮挡角 → 该掩体对此威胁失效。 |
| **Posture（姿态）** | Stand / Crouch / Prone / Crawl / Peek / Vault / Slide / Dazed / Downed 等，决定眼高、轮廓采样点、移动与射击系数。 |
| **Contact（接触）** | 感知系统里的一条敌情记录：位置、速度、阵营、置信度、来源（看见/听到/无线电）、时间戳。 |
| **Threat Field** | 8m 分辨率的威胁代价场：弹道密度 + 已知敌人影响 + 开阔度，叠加到寻路代价上，形成"杀伤区"。 |
| **Suppression（压制）** | 0–1 的连续量，由近失弹、爆炸、友军倒下等累加，分级影响精度、姿态与换位意愿。 |
| **Morale / Nerve** | 单位士气与胆量：受伤亡、压制、弹药、补给、班长存亡影响，决定是否会溃散或投降。 |
| **Downed / Wounded** | 生命值耗尽但尚未阵亡的状态：会失血、能爬行、能用手枪还击、可被救回。 |
| **Vitality** | 隐藏的"运气"值，每次倒下衰减，归零即阵亡。 |
| **FOB** | 前沿作战基地：兵力上限、补给存储、建造半径、情报半径、胜负条件的核心。 |
| **Supply Chain** | 从后方基地经道路连接到各 FOB 的链路，断点之后的所有 FOB 会断供瘫痪。 |
| **Intel** | 情报条目（兵力/装甲/基地位置/空中/弹药资金/下一步计划），带有效期，可来自侦察或俘虏口供。 |
| **Sim Tick** | 模拟层的固定步进（30Hz），与渲染帧率解耦。 |
| **LOD(AI)** | AI 更新频率与精度的距离分级：Full / Reduced / Dormant。 |
