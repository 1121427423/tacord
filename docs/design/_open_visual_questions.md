# 待人工确认项（视觉 / 手感）

来源：`assets/` 下两段官方预告片。本环境只能做抽帧与色彩统计（见 `00-overview.md` §0.4），
**无法做视觉判读**，因此以下条目需要在真机上人眼核对后回填。

| # | 问题 | 为什么重要 | 影响的设计参数 | 结论 |
| --- | --- | --- | --- | --- |
| 1 | 相机默认俯角是多少？可缩放范围？ | 决定俯视可读性、单位屏幕占比、UI 尺寸、掩体高亮的可见性 | `camera.pitch`（当前假设 20°–75°）、`camera.distance`（15–120m） | ☐ 待填 |
| 2 | 单位在屏幕上的像素高度（默认缩放下）？ | 决定角色比例、语音气泡字号、状态条尺寸 | 角色高度 1.8m → 屏幕上 ? px | ☐ 待填 |
| 3 | HUD 布局与信息密度？ | 决定我们要做"极简 + 悬浮检视"还是"常驻状态条" | UI 原型方向 | ☐ 待填 |
| 4 | 交火时是否有镜头切换 / cinematic 跟随？ | 决定 D-7（是否做只读跟随视角）的优先级 | 相机系统工作量 | ☐ 待填 |
| 5 | 单位是否有常驻血条/弹药条？还是选中才显示？ | 影响信息可读性与"指挥官视角"的沉浸感 | UI 默认开关 | ☐ 待填 |
| 6 | 掩体/视野是否有可视化辅助（例如半透明敌人可见区）？ | 我们计划做"按住 Alt 显示掩体评分热力"，需确认是否与参考风格冲突 | 可读性系统设计 | ☐ 待填 |
| 7 | 交火节奏：平均一个交火循环多久（探身→射击→缩回）？ | 校准我们的 `fire discipline` 参数（1.0–1.6s 暴露窗口） | `ai_weights.fire_discipline` | ☐ 待填 |

**核对方法**：在 macOS 上以 1/4 速度播放两段视频，逐条记录时间码与结论，回填本表并标注日期。
回填后，把受影响的参数同步更新到 `sim/data/*.ron` 与对应设计文档。
