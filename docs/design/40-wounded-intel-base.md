# 40 · 伤员链路、情报战、载具与基地

## 40.1 伤员系统（支柱 P5：绝不丢下任何人）

### 40.1.1 倒下，但没有阵亡

生命值归零 → 进入 `Downed` 状态（不是死亡）：

```
Downed {
   bleed_timer: 60s（45–90s，取决于致命部位、医疗等级、是否冬季/沙漠）
   vitality: 100 → 每次倒下 -25 ± 8（隐藏值，"运气"）
   can_crawl: fitness > 0.3 && 未命中双腿
   armed: 手枪 / 步枪（单手，精度 ×0.35）/ 空手
   calling_out: 每 5–8 秒喊一次 "MEDIC!"（声音事件，90m）
}
```

- **爬行求生**：`Downed` 单位会自己爬向最近的可用掩体（复用 §20.1 的掩体系统，姿态 `Crawl`，采样点 350/200mm——趴着真的更难打中）。爬速 0.15 移速系数（约 0.5 m/s），被压制时改为原地蜷缩。
- **还击**：被拖行时仍可用手枪还击（单手，精度 ×0.35，射速 -50%）——这是"伤员被拖走时也会一直用手枪还击"的实现。
- **失血**：`bleed_timer` 归零 → 转为 `Dead`。出血速度受部位影响（躯干快、四肢慢；四肢命中会先"流血 debuff"：持续掉血直到被包扎）。
- **运气用完**：`vitality ≤ 0` → 下一次倒下直接 `Dead`。UI 上不显示 vitality 数值，只显示"重伤 / 危急"等模糊状态（保持张力）；老兵 vitality 初始值更高。

### 40.1.2 救援流程（班组层调度）

```
1. 触发：单位进入 Downed → 声音事件 + 班组黑板写入 {wounded: [..]}
2. 班组评估（2Hz）：
     risk = threat_field(wounded.pos) 与 路径上的威胁
     if risk > 0.55 且 无掩护 → 先执行 SUPPRESS（全班/部分火力压制威胁方向 4–8 秒）
                                 或 请求烟雾弹 / 请求班内机枪压制
     if risk <= 0.45 或 压制已生效（威胁场下降 ≥ 30%）→ 派 1–2 人执行 RESCUE
3. RESCUE 执行：
     - Runner（1 人）：冲刺到伤员处（Sprint，暴露大）
     - 抓取（0.6s）：抓住肩膀
     - Drag（0.8 m/s，拖者与被拖者都处于高暴露姿态）：拖向最近的安全掩体/FOB/医疗点
     - Cover man（第 2 人，若有）：**倒退着走并射击**（bounding backwards），保持在伤员与威胁方向之间
4. 到达安全点（blocking ≥ 0.6 的掩体）→ AID（见下）或交给担架队
```

- 救援**不是免费的**：一次救援让该班 1–2 人脱离战斗 10–30 秒，且拖行时两人都是高价值目标。敌方 AI 会故意打担架队吗？见 §40.1.5 的受保护规则（默认：受保护的医疗单位不会被**优先**射击，但会被误伤；可配置）。
- 玩家可下达 `PRIORITY: SAVE WOUNDED`（提升救援优先级）或 `PRIORITY: HOLD`（暂缓救援，保住战力）—— 这是一个真实的道德/战术抉择，符合"绝不丢下任何人"的张力。

### 40.1.3 就地救治

| 救治者 | 时间 | 消耗 | 结果 |
| --- | --- | --- | --- |
| 战友（Buddy aid） | 10 s | 1 个急救包 | HP 恢复到 35%，停止出血，附加 `BANDAGED` debuff（15s 内移速 -15%） |
| 医护兵（Medic） | 5 s | 1 个医疗包 | HP 恢复到 55%，清除 debuff，压制清零 |
| 自救（伤员自己，仅四肢伤） | 20 s | 1 个急救包 | HP 恢复到 20% |

- 急救包：每人携带 1 个（用完 → 只能靠医护兵/FOB）；医护兵携带 3 个医疗包（可从 FOB 补充，消耗补给）。
- **CPR**：`bleed_timer` 归零后进入 `CRITICAL`（30 秒窗口），此时只有医护兵的 CPR 能救回（8s，成功率 60% ± 医疗等级），成功 → `Downed` 且 `vitality - 30`。这段是"倒下但没有阵亡"的最戏剧化时刻。

### 40.1.4 医疗帐篷与担架队

建成 `Field Hospital`（医疗帐篷）后，FOB 生成 **2 支担架队（每队 2 人）**，标记为 `MEDIC`（受保护，见下）：

```
担架队流程：
  DISPATCH → 跑向最近的 Downed/Dead 伤员（优先级：可救的 > 最近的 > 军衔高的）
  LOAD     → 两人抬起（1.5s），抬行速度 1.3 m/s（比拖行快 60%）
  HAUL     → 返回帐篷
      ├ 若一名担架兵中弹倒下 → 另一人改为 DRAG（0.7 m/s）继续前进（"只剩一人时就拖着走"）
      └ 若两人都倒下 → 任务挂起，等下一队/其他单位接管
  TREAT    → 进入治疗队列（床位 4 张，每张 20s，消耗药品补给）
  RETURN   → 治愈后单位重新进入可用人力池，从兵营/FOB 归队（走回战场）
```

- **也会回收阵亡者**：`Dead` 单位可被担架队回收（1.0 m/s，单人可拖）→ 进入 KIA 名册（影响士气统计与"重建"逻辑：回收的尸体可回收装备，且不算"失踪"）。
- **敌方尸体**：可搜刮（武器/弹药/文件 → 情报），也可被回收（出于战斗清理，或玩家下令"清理战场"）。
- 医疗帐篷容量：4 床位，队列上限 8；超出的重伤员躺在帐篷外（等待/失血）。升级（研究/补给）可扩到 8 床位。
- **空中后送（Helipad）**：建成直升机停机坪后，可请求 Medevac：直升机飞来（受敌方防空/FPV 威胁），一次运走 2 名重伤员回后方（治疗更快、不占本地床位，但直升机是重大损失风险）。

### 40.1.5 受保护规则（医疗单位）

- 担架队/医护兵带 `MEDIC` 标记 → 敌方 AI 的目标选择效用 **-0.35**（不会优先打他们），但：
  - 如果他们开火（规则：医护兵只在被直接攻击时自卫，担架兵默认不还击）→ 立即失去保护，且该阵营全局失去保护 60 秒（"你先开的枪"）；
  - 误伤照常（跳弹、爆炸、压制火力、FPV）；
  - 玩家/敌方指挥官可下达 `IGNORE_MEDIC_RULES`（战争罪行开关，默认关；开启后敌方也会同样对待你的医疗单位，并带来士气/舆论后果——战役里体现）。
- 这是一条**设计上的道德选择**，也是把"是否会打担架队"变成玩法。

## 40.2 俘虏与情报战（支柱：会开口的俘虏）

### 40.2.1 投降（Surrender）

必须**同时满足**（罕见事件，目标频率：每局 0–3 次）：

| 条件 | 阈值 |
| --- | --- |
| 战友状态 | 班内全部 `Downed`/`Dead`，或最近的可支援友军 > 60m 且路径威胁 > 0.7（"不会有人来救他"） |
| 被压制 | `suppression ≥ 0.75` 持续 ≥ 3 秒 |
| 退路被切断 | 到己方 FOB/防线的路径威胁 > 0.8，或被包围角 ≥ 240°（周围 40m 内敌人在多个方向） |
| 士气 | `morale < 0.25` |
| 个性检定 | `rng() < (1 - nerve) * 0.6`（老兵几乎不投降，新兵容易） |
| 距离 | 最近敌人 < 30m（能听见喊话） |

表现：丢下步枪（武器实体掉在地上，可被捡走）、举手（0.5s 动作）、喊 `DON'T SHOOT!`、停止移动、进入 `SURRENDERED` 状态。

- **`SURRENDERED` 不是无敌**：仍会被误伤（其他单位的流弹/爆炸、没看到他举手的新兵、被压制的射手）。这是真实的残酷，也是"投降有风险"。
- **假投降（可选）**：低概率（5%）的 `nerve` 高的单位会假投降，被押送时寻找机会夺枪反抗（增加张力；默认开启但概率低）。

### 40.2.2 押送与审问

```
1. ESCORT 分配：指挥层派 1 名士兵脱离战斗（战力 -1，这是押送的代价）
2. HANDCUFF（2s）：走到俘虏旁上铐（期间两人都暴露）
3. ESCORT 步行回基地（速度 0.8 m/s，俘虏跟随）：
     - 途中每隔 3–8 秒吐露一条情报（顺序随机，由 rng 决定）
     - 押送者可以射击（但会拖慢），俘虏在战斗中被流弹击中的概率存在
     - 敌方（俘虏的原部队）会试图救回/灭口（AI 会评估：救回 vs 阻止情报泄露 → 可能直接开火打俘虏）
4. 抵达 FOB → 俘虏进入 POW 状态（关押/移交）
```

### 40.2.3 情报条目（Intel）

俘虏会全部交代——而且**这些情报在那一刻都是真的**（直接读取敌方 AI 黑板，不是编造）：

| # | 情报 | 内容 | 有效期 |
| --- | --- | --- | --- |
| 1 | 剩余人数与兵种 | 精确到"还剩 23 人，其中 2 挺机枪、1 具 RPG" | 30 s（战损实时变化） |
| 2 | 装甲/载具 | 型号、位置、状态（履带/弹药/油量） | 60 s（会移动） |
| 3 | **基地位置** | 所有 FOB 的坐标 | 120–180 s（会转移/放弃） |
| 4 | 空中单位 | 直升机/无人机操作员数量与位置 | 45 s |
| 5 | 弹药与资金 | 库存补给量、弹药百分比 | 90 s |
| 6 | 补给路线 | 卡车路线与班次 | 120 s |
| 7 | **下一步计划** | 敌方指挥官当前 objective + 目标点 + 预计时间（"20 分钟后从北面进攻你的 2 号 FOB"） | 90 s |
| 8 | 阵地与工事 | 已知的地道入口、机枪巢、雷区（画在地图上） | 300 s（静态） |

- **情报生效**：基地位置情报 → 立即在战术地图/雷达上点亮（图标 + 时间戳 + 过期倒计时）。计划情报 → 在地图上显示一条"预计进攻路线"的虚线箭头（会随敌方实际变更而失效，UI 上要能显示"已过期"）。
- **情报面板**：每条情报显示来源图标（口供 / 侦察 / 无线电截获 / 无人机）、时间戳、可信度（口供 > 侦察）、过期倒计时。过期情报自动灰显（不自动删除，让玩家自己判断——但 AI 不会用过期的情报做决策）。
- **双向**：己方士兵被俘 → 敌方指挥官获得同样 8 类情报，并**据此行动**（重新分配兵力、改变进攻方向、伏击你的补给线）。这是"情报是资源"的另一半。

### 40.2.4 俘虏处置

| 阵营 | 处置 | 结果 |
| --- | --- | --- |
| **正规军** | 移交（Hand over）到 FOB → 俘虏**倒戈**：`"I'M WITH YOU NOW."` | 成为可指挥单位：装备降一级（用缴获武器）、弹药 2 匣、`loyalty 0.6`（其原部队在 40m 内时有概率叛回）、士气对原阵营攻击 +10% |
| **叛军** | 关进**地道牢房**（tunnel cell） | 反复审问：每 45 秒泄露一条"我方**当前**部队位置"（半径 60m 的模糊区域）→ 敌方指挥官据此调度（伏击/炮击/FPV）。逃脱机制：守卫 < 1 或门被破坏 → 逃脱为徒手单位 → 找到武器则重新武装为敌方单位 |

- **地道牢房**同时是叛军的基地特色：地下网络（入口、通道、牢房、突袭出口），见 §40.4.5。

### 40.2.5 情报与 AI 的闭环

```
侦察/口供 → Intel 表 → 指挥层 AI 的 objective 评估（"敌方 2 号 FOB 只有 8 人防守，且补给线 300m 处有个好伏击点"）
                     → Mission 分配 → 玩家看到敌人在做什么（如果他有侦察覆盖）
```
敌方 AI 用**完全相同**的代码路径和数据结构（P6）。唯一区别是它拿到的 Intel 来自它自己的侦察与它俘获的你的士兵。

## 40.3 坦克与 FPV 无人机

### 40.3.1 坦克（有分量的钢铁）

**装甲分区**（每区独立等效厚度 mm 与倾角）：

| 区 | 等效厚度（示例值） | 命中效果 |
| --- | --- | --- |
| 首上装甲 | 550 | 难穿 |
| 首下装甲 | 380 | 可穿（跳闸/传动） |
| 侧前 | 300 | 可穿 |
| 侧后 | 180 | 易穿（弹药架/引擎） |
| 后部 | 120 | **最易穿**（RPG 绕后的动机） |
| 顶部 | 60 | 攻顶（无人机/楼上手雷/俯射）极有效 |
| 履带 | 90（结构） | 打断 → immobilize（趴窝，但炮塔仍可射击 → 变成固定火力点） |
| 炮塔环 | 150 | 击中 → 炮塔卡住（不能转向） |
| 观瞄 | 40 | 击中 → 精度/视野大幅下降 |

```
穿透判定：
  eff_thickness = base_thickness / cos(impact_angle)^1.1      // 倾角生效
  pen_at_range  = weapon.pen0 * (1 - 0.15 * (range_km)^1.2)
  if impact_angle > 70°                     → 强制跳弹
  elif impact_angle > 60° && eff > pen      → 跳弹（可造成外部设备损伤）
  elif pen_at_range >= eff_thickness        → 穿透（伤害 × 剩余穿深系数）
  else                                      → 未穿透（叮！跳弹视觉 + 乘员士气打击）
```

**内部模块**（穿透后按命中位置掷骰）：

| 模块 | 效果 |
| --- | --- |
| 引擎 | 机动 -60% / 停车（冒黑烟，容易被打） |
| 传动/履带 | 无法移动（`IMMOBILIZED`），可继续射击 |
| 炮塔环 | 炮塔转速 → 0 |
| 主炮 | 精度 -70% / 无法开火 |
| 弹药架 | **8% 概率殉爆** → `TURRET POP`（炮塔被炸飞：物理抛射 + 落地成为掩体 + 坦克永久摧毁 + 大范围爆炸） |
| 乘员（车长/炮手/驾驶员/装填手） | 减员 → 射速/机动/视野下降；全灭 → 弃车（乘员下车成为步兵，带手枪/步枪） |

- **撞墙**：`质量 × 速度` vs 材质结构 HP → 墙倒塌（柱破坏管线），坦克速度下降，可能卡住（履带被钢筋缠住 → 短暂 immobilize）。这是"坦克能撞穿墙壁"的实现。
- **坦克对步兵**：同轴机枪 + 高爆弹（对掩体后的步兵非常有效，能直接打掉掩体）；但对**贴身步兵**（< 15m，尤其是背后）很脆弱（肉搏/手雷/燃烧瓶）。
- **RPG 绕后**：RPG 射手的 AI 会计算候选射击位：
  ```
  position_score = P(pen | 命中区装甲 & 角度 & 距离) × expected_damage
                 - exposure_risk(路径与站位的 threat_field)
                 + 0.3 * (能否从侧面/后方接近)
  ```
  选择 top 位置后，用掩体图 + 威胁场规划一条**尽量低暴露**的接近路线（常常是绕一整条街）。被打断（被压制/受伤）会重新评估——有时他会趴在原地等压制解除，有时会放弃。
- **Hull-down（车体隐蔽）**：坦克 AI 会寻找能遮住车体的地形/残骸，只露出炮塔（复用掩体系统的 blocking 概念，只是采样点是车体/炮塔两组）。
- 坦克的**噪声与视野**：引擎声 500m 可听（重要的预警）；视野受舱盖开闭影响（闭舱视野 -40%，但不会被手雷/狙击打中乘员）。

### 40.3.2 FPV 自杀无人机

| 属性 | 值 |
| --- | --- |
| 操作员 | 1 名士兵（手持控制器，移动速度 -50%，暴露风险高；可被优先狙击——他是高价值目标） |
| 速度 | 巡航 22 m/s，俯冲 40 m/s |
| 噪声 | 60m 可听（独特的高频嗡嗡声）—— **玩家与 AI 听到同样的声音** |
| 结构 | HP 15（步枪 1–2 发、霰弹极易、机枪扫射可打掉） |
| 视场 | 60° 摄像机（操作员视角，可被 UI 切换到"无人机视角"观察） |
| 航程 | 3 km，滞空 8 分钟 |
| 战斗部 | 相当于 1 枚手榴弹（对坦克顶部攻击时有效，可打断履带/摧毁观瞄） |

**士兵的反制链条**（AI 自动，玩家可见）：

```
1. 听到（60m 内）→ 抬头搜索（2s）：把搜索扇区加入注意，视锥向上/向声源
2. 看见（视锥内 + 距离 < 80m）→ 开火：命中率 = f(武器散布, 距离, 无人机速度, 姿态)
     卧倒射击最稳、站立最差；霰弹枪/机枪最有效；被压制时几乎打不中
3. 未能击落且距离 < 12m（约 0.5s 到撞击）→ DIVE（扑倒）：
     成功率：卧倒 55% / 蹲 35% / 站立 10%（还取决于 fitness 与 initiative）
     成功 → 爆炸伤害 × 0.35；失败 → 全额伤害
4. 撞击/自爆 → 伤害 + 击飞（见 §30.4）
```

- 无人机是**稀缺资源**（消耗 FOB 补给/工厂产能），操作员阵亡 → 该无人机失控坠落。
- 玩家对策：优先打操作员（情报里会告诉你有几个操作员）、用霰弹枪编组防空、让班组散开（AI 会自动增大间距若检测到 FPV 威胁）。

## 40.4 基地建造与补给（支柱 P6）

### 40.4.1 FOB（前沿作战基地）

| 属性 | 值 |
| --- | --- |
| 兵力上限 | +20（每座；基础 20 + 20 × FOB 数） |
| 补给存储 | 500 单位 |
| 建造半径 | 60 m（建筑只能建在此范围内） |
| 情报/雷达半径 | 200 m（此范围内的已知情报自动显示在地图） |
| 占领半径 | 25 m |
| 结构 HP | 1200（分段破坏） |
| **失败条件** | **失去最后一座 FOB → 失败**（也用于敌方：占领/摧毁敌方所有 FOB → 胜利） |

- FOB 需要"落在相对平坦的地面"（放置合法性检查：坡度、是否被水淹、是否与现有建筑重叠、是否在敌人射界内——后者是**建议**而非禁止，玩家可以冒险）。
- 放下蓝图 → 消耗补给 → **士兵走过去亲手建造**（2–4 名工人，人多加速但递减：1 人 100s，2 人 60s，3 人 45s，4 人 38s）→ 期间工人被打死则暂停（其他工人会接替；无人则蓝图留在原地，进度保留）。

### 40.4.2 补给链（生命线）

```
后方基地（Home Base，永不断供）
   │
   ├── 道路（自动生成：从 FOB 到最近己方补给源，路径规划时避开高威胁区）
   │        ↓
   ├── FOB #1 ←── 卡车往返（容量 100 补给/趟，速度取决于路况与威胁）
   │        ↓
   └── FOB #2 ←── （依赖 FOB #1 与后方之间的链路）
```

- **铺路**：FOB 建成后自动寻路生成道路（修改地形材质/贴花 + 提升卡车速度 40%）。道路本身可被破坏（炸出弹坑 → 卡车绕行/停滞）。
- **卡车**：周期发车（取决于 FOB 的补给缺口），沿路行驶；会被**伏击**（敌方 AI 评估"切断这条线能瘫痪 N 个 FOB" → 派小队在路边掩体埋伏 → 卡车经过 → 开火 → 卡车被毁 → 链路断开 60–120 秒直到新卡车/护送）。
- **断供（Starved）**：链路被切断 → 断点之后的所有 FOB 依次进入 `STARVED`，按时间逐步恶化：

| 断供时长 | 后果 |
| --- | --- |
| 0 s | 停止治疗（医疗帐篷停止工作，伤员不再被治愈） |
| 30 s | 停止补弹（单位无法在 FOB 补弹） |
| 60 s | 无法建造/修理（工事被打坏就修不了） |
| 120 s | 兵力上限失效（不能补充新兵） |
| 180 s+ | 士气持续下降（surrender 概率上升、BROKEN 阈值提高） |

- 玩家对策：派兵护送（Escort 任务）、清剿伏击点、修路、放弃远端的 FOB（主动拆除可回收 50% 补给）。
- **敌方 AI 也懂这套**：它会主动评估"切断补给 vs 攻击 FOB"的收益，并优先打补给线（因为代价小、收益大）。这让"为什么敌人在打我的卡车"变成可理解的行为。

### 40.4.4 工事（任何地方，需要在建造半径内或工程兵抵达）

| 工事 | 时间 | 补给 | 效果 |
| --- | --- | --- | --- |
| 战壕 Trench | 40 s/段（5m） | 15 | 降低姿态高度（掩体类型 TRENCH），连通机动，可挖通成网络；被爆炸填平（柱高度恢复） |
| 混凝土墙 Concrete Wall | 30 s/段 | 25 | 高掩体（HIGH_WALL），抗轻武器，可被坦克/炸药炸开 |
| 沙袋 Sandbag | 20 s/段 | 10 | 中掩体，便宜，被打坏快 |
| 铁丝网 Wire | 25 s/段 | 8 | 减速 60%，阻挡冲刺/翻越；可爆破/剪断（3s） |
| 地雷 Mine（AP/AT） | 10 s/颗 | 12/30 | 触发式（AP：杀爆；AT：打断履带）；**会被己方记录但需要玩家小心**（AI 知道己方雷区，会绕行；但被追击溃逃的单位可能踩进去） |
| 反坦克障碍 | 35 s | 20 | 阻挡载具通行（可爆破） |
| 机枪巢 MG Nest | 60 s | 45 | 射界 +30%、精度 +25%、正面防护（HIGH_WALL）；机枪手在里面很难被压制 |
| 瞭望塔 Watchtower | 90 s | 60 | 视野 +25%、视距 +50%、可作为观察/狙击位；**敌方优先攻击目标**（高价值且脆弱） |

- **所有东西都能被打碎，也都能修回来**：工事有 HP，破坏 → 残骸（可能仍有部分掩体价值）→ 工程兵可修（消耗补给，速度 = 建造速度）。
- **叛军地道网络**（阵营特色）：
  - 入口（可隐藏）/ 通道 / 出口 / 牢房；
  - 单位进入地道后**不可见**（除热成像、监听、或敌人已发现入口 → 在地图上标记）；
  - 从出口"冒出"（1.2s 的出击动画，暴露窗口）→ 突袭；
  - 可被发现（侦察/无人机/口供/监听挖掘声）、可被炸塌（封锁通道 → 内部单位被埋：阵亡或困住等待挖通）；
  - 战术价值：绕过补给线封锁、在 FOB 内部附近突袭、转移俘虏。

### 40.4.5 占领与失败

```
占领 FOB：
  条件：占领半径内无敌方有生力量（Downed 不算有生力量，但会阻止占领直到被拖走/清除）
     且 己方至少 1 名单位在半径内
     且 持续 30 秒（有 UI 进度环，双向争夺时进度回退）
  结果：FOB 易主，内部存储补给被新主人接收，其建造半径内的建筑一并易主（若未完成则保留蓝图）
```

- **AI 遵循与你完全相同的规则，而且它盯上了你的 FOB**：敌方指挥层会评估每个 FOB 的价值（兵力上限贡献 / 补给链影响 / 距离 / 防守兵力估计 from Intel）→ 选最优目标 → 组织进攻（先切断补给 → 压制 → 包抄 → 突入 → 占领）。
- **失败**：己方 FOB 数 = 0 → 失败。玩家可主动放弃/拆除 FOB（回收 50% 补给，收缩防线，这是合法战术）。
- **胜利条件**（遭遇战）：占领/摧毁敌方所有 FOB，或达成任务目标（守住 20 分钟 / 护送 / 抓捕）。

### 40.4.6 建造的"亲手感"（P6 的表现层）

- 放下蓝图 → 地面出现粉笔线轮廓（不是成品）→ 工人走过去（路径、掩体、遇敌交战都会发生）→ 施工动画（搬沙袋、挖土、浇筑、敲打）+ 逐渐成型的**分段模型**（视觉上从 0% → 100% 长出来，而不是淡入）→ 完成时有一下"落地"的音效与尘土木屑。
- 工人被打死/压制 → 工地停摆（尘土落定）。这个"停摆"的视觉是"没有什么是凭空建成的"的最佳说明。
